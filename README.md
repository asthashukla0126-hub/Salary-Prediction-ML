
# Salary Prediction using Linear Regression

## Overview
It predicts salary based on years of experience
using a Linear Regression model.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Algorithm
Linear Regression

## Workflow
1. Load the dataset
2. Separate features and target
3. Split data into training and testing sets
4. Train the Linear Regression model
5. Predict salaries using test data
